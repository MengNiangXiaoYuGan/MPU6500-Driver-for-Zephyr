 # 基于Zephyr操作系统的MPU6500-IMU驱动库

 ## 简介
 - 该库基于Zephyr自带的MPU6050库进行拙劣的模仿，保持了MPU6050库内读取和`DATA_READY`触发功能的状态下，添加了以下功能
 - 1. 添加了更多的触发方式，例如`FIFO_OVERFLOW`,以及`MOTION`触发，触发模式是锁存的，启动触发后将无法取消，触发（我也不知道为什么zephyr的sensor trigger set 居然没有取消触发的选项，很奇怪
 - 2. 在motion触发的选项中，根据mpu6500的数据手册设定了触发，并且进入低功耗模式，整体功耗可以降低一半左右，但是没有关闭陀螺仪
